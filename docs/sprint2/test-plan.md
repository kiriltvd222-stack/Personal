# План тестування (Test Plan) — Проєкт «Персонал+»

## 1. Опис продукту та межі тестування

«Персонал+» — це корпоративна HRM-система (**версія 1.1**, оновлена за результатами аудиту вимог у Спринті 2), що включає вебмодулі (вхід, Admin, PIM, Leave, Time, Recruitment, My Info) та окремий Java-модуль бізнес-логіки (`ua.kpi.tzyapz.personal`) на JDK 17.

- **Межі тестування:** Вебінтерфейс (Chrome/Firefox, роздільна здатність від 1280×720), правила обчислення відпусток, нарахувань та валідації даних у Java-класах (`LeaveCalculator`, `PayrollCalculator`, `EmployeeValidator`), процеси погодження заявок, сповіщення (Email та внутрішньосистемні), перевірки безпеки та продуктивності.

## 4. Ризики і припущення

*   **Припущення:** Demo-стенд буде стабільно доступний під час тестування; дані на ньому можуть скидатися періодично, тому тестові профілі доведеться створювати заново для кожного прогону.
