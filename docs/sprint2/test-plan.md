# План тестування (Test Plan) — Проєкт «Персонал+»

## 1. Опис продукту та межі тестування
«Персонал+» — це корпоративна вебсистема управління персоналом та внутрішніми бізнес-процесами (HRM). Система забезпечує облік співробітників, ведення організаційної структури, подачу та погодження заявок на відпустку, а також формування звітів.
* **Межі тестування:** Вебінтерфейс користувача (кабінет працівника, кабінет HR, панель адміністратора), бізнес-логіка розрахунку залишків днів відпустки, процеси погодження, безпека даних та інтеграція імпорту співробітників із CSV.

## 3. Незастосовні типи тестування та обґрунтування
Оскільки «Персонал+» є хмарним вебдодатком для управління внутрішнім персоналом (SaaS), наступні типи тестування не застосовуються через природу продукту:
* **Інсталяційне тестування:** *Не застосовується*, оскільки застосунок розгортається на сервері як вебсервіс і не має локального дистрибутива чи інсталяційного пакета для кінцевих користувачів.
* **Тестування витоків пам'яті на апаратному рівні (під вбудовані системи):* *Не застосовується*, оскільки проєкт є корпоративним вебрішенням, а не мікроконтролерним чи мобільним софтом з жорсткими обмеженнями апаратної пам'яті пристрою.

## 4. Інструменти, середовище та тестові дані
* **Середовище тестування:** Тестовий хмарний сервер (Staging), браузери Google Chrome, Mozilla Firefox, Safari.
* **Тестові дані:** Набір згенерованих облікових записів (HR, керівники, звичайні працівники з різними балансами днів відпустки), тестові CSV-файли для імпорту.
