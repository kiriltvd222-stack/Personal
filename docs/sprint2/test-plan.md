Незастосовні типи тестування та обґрунтуванняЗгідно з обмеженнями продукту (розділ 2.3 SRS 1.1), наступні типи тестування не застосовуються:Інсталяційне тестування: Не застосовується, оскільки «Персонал+» розгортається як вебзастосунок на віддаленому демо-стенді (opensource-demo.orangehrmlive.com), а Java-модуль є бібліотекою (.jar), а не кінцевим додатком для локального встановлення користувачем.Тестування мобільного застосунку: Не застосовується, оскільки прямим обмеженням версії 1.1 є відсутність мобільного додатка (підтримуються лише десктопні браузери Chrome/Firefox із роздільною здатністю від 1280×720).Тестування зовнішніх інтеграцій: Не застосовується у версії 1.1, оскільки система не інтегрується із зовнішніми SMS-шлюзами, месенджерами (Viber), державними реєстрами (ДПС) або порталами вакансій.4.
