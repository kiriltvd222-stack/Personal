План тестування (Test Plan) — Проєкт «Персонал+»

Опис продукту та межі тестування
«Персонал+» — це корпоративна HRM-система (версія 1.0), що включає вебмодулі (вхід, Admin, PIM, Leave, Time, Recruitment, My Info) та окремий Java-модуль бізнес-логіки (ua.kpi.tzyapz.personal) на JDK 17[cite: 16, 17, 20].

Межі тестування: Вебінтерфейс (Chrome/Firefox, розширення від 1280×720), правила обчислення відпусток і зарплат у Java-класах (LeaveCalculator, PayrollCalculator, EmployeeValidator), процеси погодження заявок та безпека[cite: 17, 20, 21].

3. Незастосовні типи тестування та обґрунтування

Згідно з обмеженнями продукту (розділ 2.3 SRS)[cite: 17], наступні типи тестування не застосовуються:

Інсталяційне тестування: Не застосовується, оскільки «Персонал+» розгортається як вебзастосунок на віддаленому демо-стенді (opensource-demo.orangehrmlive.com), а Java-модуль є бібліотекою (.jar), а не кінцевим додатком для локального встановлення користувачем[cite: 17].
Тестування мобільного застосунку: Не застосовується, оскільки прямим обмеженням версії 1.0 є відсутність мобільного додатку (підтримуються лише десктопні браузери Chrome/Firefox із роздільною здатністю від 1280×720)[cite: 17].
4. Інструменти, середовище та тестові дані

Середовище тестування: Демо-стенд https://opensource-demo.orangehrmlive.com, JDK 17 для Java-модуля бізнес-логіки[cite: 17, 20].
Тестові дані: Облікові записи Admin / admin123, тестові профілі працівників із різними лімітами відпусток, РНОКПП (10 цифр), валідні/невалідні email-адреси для перевірки EmployeeValidator[cite: 17, 21].
