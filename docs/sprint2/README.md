## Нормативи (команда з 3 осіб) і виконання

| Норматив | Вимога | Фактично виконано |
| :--- | :--- | :--- |
| Прийнятих дефектів SRS із 24 закладених | ≥ 12 | **15** |
| Дефектів на кожен із 6 критеріїв | ≥ 2 | **Від 2 до 3 на кожен критерій** |
| Рівнів тестування у плані | Усі 7 | **7 рівнів** |
| Застосовних типів тестування | ≥ 9 | **9 типів** (з деталізованими цілями та описами під стенд) |
