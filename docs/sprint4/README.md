# Звіт з автоматизації тестування (Спринт 4)
**Продукт:** П3 «Персонал+» (Модуль `personal`)

## 1. Покриття вимог бізнес-логіки (SRS)
Команда успішно покрила юніт-тестами (JUnit 5) всі вимоги до бізнес-логіки з розділу 5 специфікації `SRS_03_Персонал_плюс.html`. Загалом написано **18 автоматизованих тестів**:

| Клас модуля | Покриті вимоги | К-сть тестів | Відповідальний |
| :--- | :--- | :---: | :--- |
| `LeaveCalculator` | BL-10, BL-20, BL-30, BL-40 | 7 | Ходячих Нікіта |
| `PayrollCalculator` | BL-50, BL-60, BL-70 | 6 | Кудря Кіріл |
| `EmployeeValidator` | BL-80 | 5 | Сиротін Максим |

## 2. Інфраструктура та запуск
- **Середовище:** Java JDK 17, Maven 3.9, JUnit 5.
- **Команда запуску:** `mvn clean test` 
- Тести інтегровані у спільний репозиторій команди з дотриманням структури Maven.
