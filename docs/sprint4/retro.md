# Протокол ретроспективи (Спринт 4)

**Дата проведення:** 17.11.2026
**Присутні:** Сиротін Максим (Scrum Master), Ходячих Нікіта, Кудря Кіріл.
**Мета:** Аналіз переходу від ручного тестування до автоматизованих юніт-тестів на Java (JUnit 5).

## Що пройшло добре (What went well)
- Швидко налаштували спільну архітектуру Maven-проєкту в GitHub-репозиторії, уникнувши проблем з розсинхронізацією коду.
- Успішно написали та прогнали 18 тестів, забезпечивши 100% покриття запланованих бізнес-вимог (BL-10 — BL-80).
- Ідеальний розподіл задач: кожен відповідав за окремий клас (`EmployeeValidator`, `PayrollCalculator`, `LeaveCalculator`), що дозволило уникнути конфліктів при злитті гілок (merge conflicts).

## Що можна покращити (What could be improved)
- Виникли невеликі труднощі на старті з налаштуванням середовища (`Project JDK is not defined` в IntelliJ IDEA), але проблему було швидко вирішено шляхом завантаження Temurin JDK 17.
- Потрібно уважніше слідкувати за структурою папок при додаванні тестів, щоб Surefire plugin завжди їх розпізнавав.
