### Примітки до змісту

- **Трекер дефектів:** Усі знайдені дефекти зафіксовані у розділі **GitHub Issues** (та продубльовані в `bug-reports.xlsx`) із відповідними мітками `severity:*`, `priority:*` та `sprint:3`.
- **Незалежність кейсів:** Кожен тест-кейс є повністю незалежним, починається з відкриття застосунку та закінчується виходом із системи/закриттям вкладки.
- **Рецензування:** Усі тест-кейси та звіти про дефекти пройшли взаємне перехресне рецензування (відмітки зафіксовані на аркуші `Review` у `test-cases.xlsx`).
