### Примітки до змісту

- **Трекер дефектів:** Усі дефекти зафіксовані у розділі [GitHub Issues](https://github.com/kiriltvd222-stack/Personal/issues?q=is%3Aissue+label%3Asprint%3A3) та продубльовані в `bug-reports.xlsx` з обов'язковими мітками `sprint:3`, `severity:*`, `priority:*` та `status:*`.
- **Незалежність кейсів:** Кожен тест-кейс є незалежним, починається з відкриття адреси демо-стенду та завершується виходом із системи (Logout).
- **Рецензування:** Усі тест-кейси рецензовані на аркуші `Review` у `test-cases_reviewed.xlsx`, а звіти про дефекти завірені коментарями рецензента в GitHub Issues та проставленням поля Reviewer у `bug-reports.xlsx`.
